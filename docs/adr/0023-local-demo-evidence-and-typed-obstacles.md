# ADR-0023 本机演示证据包与完整类型化障碍物

## 状态
已接受

## 背景

在当前笔记本电脑环境下，本机 MuJoCo/Webots 路线已经成为实际可行的演示路线。前一阶段的类型化场景工作在 API 层引入了 `box` / `sphere` / `cylinder` 几何类型，但本机仿真 schema 与世界绑定仍主要将障碍物按圆柱体处理。演示脚本也缺少一个统一命令，用于生成答辩评审所需的任务、控制、回放与审计证据。

## 决策

1. 将类型化几何纳入后端无关的 Python 仿真 schema，以及 C++ 本机仿真场景模型。
2. 按障碍物形状计算本机障碍物间隙：
   - 圆柱体：使用带垂直方向裁剪的径向占地轮廓；
   - 球体：使用三维径向间隙；
   - 盒体：使用 AABB 最近点间隙。
3. 为圆柱体、球体和盒体障碍物生成 MuJoCo geoms 与 Webots Solid 节点。
4. 允许本机 MuJoCo/Webots 演示脚本加载外部场景 JSON 文件。
5. 新增演示证据生成器，将任务提交、任务确认、本机移交、可选急停、回放查询、审计查询与事件导出运行结果生成 JSON 和 Markdown 工件。

## 影响

- MuJoCo/Webots 演示场景可以在不修改代码的情况下切换。
- API 场景资产与直接仿真场景文件现在共享相同的障碍物几何语义。
- 答辩演示证据可通过 `scripts/run_demo_evidence.py` 复现生成。
